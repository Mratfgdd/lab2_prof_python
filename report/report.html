Один студент – це словник (dict) з п'ятьма полями (таблиця 2). Такий формат відповідає JSON-like даним, легко серіалізується і дозволяє звертатися до полів за ключем. @track_operation("групування за групою")
def group_students(students: list[Student]) -> dict[str, list[Student]]:
    groups: defaultdict[str, list[Student]] = defaultdict(list)
    for student in students:
        groups[student["group"]].append(student)
    return dict(groups)

def count_students_by_group(students: list[Student]) -> Counter[str]:
    return Counter(student["group"] for student in students)

6. Приклади ключових конструкцій

6.1. Comprehensions і generator expression

Set comprehension збирає унікальні значення поля, dict comprehension будує індекс, list comprehension фільтрує, а generator expression рахує суму без проміжного списку:

def get_unique_values(students: list[Student], field: str) -> set[Any]:
    return {student[field] for student in students}

def create_student_index(students: list[Student]) -> dict[int, Student]:
    index = {student["id"]: student for student in students}
    if len(index) != len(students):
        raise ValueError("Ідентифікатори студентів повторюються")
    return index

def filter_items(items: list[Student], predicate: Predicate) -> list[Student]:
    return [item for item in items if predicate(item)]

@measure_time
def calculate_average(students: list[Student]) -> float:
    if not students:
        return 0.0
    return round(sum(student["average_grade"] for student in students) / len(students), 2)

6.2. *args

Функція calculate_stats приймає довільну кількість значень; при виклику генератор розпаковується оператором *: calculate_stats(*(s["average_grade"] for s in students)).

def calculate_stats(*grades: float) -> GradeStats:
    if not grades:
        return GradeStats(0, 0.0, 0.0, 0.0)
    return GradeStats(
        size=len(grades),
        average=round(sum(grades) / len(grades), 2),
        minimum=min(grades),
        maximum=max(grades),
    )

6.3. **kwargs

create_student(**fields) формує запис з іменованих аргументів і перевіряє його: усі поля на місці, група не порожня, середній бал у межах 0–100. build_summary(students, **options) приймає налаштування top і min_grade; невідомі ключі знаходяться різницею множин ключів і дають TypeError.

def create_student(**fields: Any) -> Student:
    missing = [name for name in REQUIRED_FIELDS if name not in fields]
    if missing:
        raise ValueError(f"Відсутні поля: {', '.join(missing)}")
    if not str(fields["group"]).strip():
        raise ValueError("Група не може бути порожньою")
    if not 0 <= fields["average_grade"] <= 100:
        raise ValueError("Середній бал має бути в межах 0-100")
    return dict(fields)

6.4. lambda

lambda використано як короткий ключ сортування та пошуку максимуму. У sort_items ключ – це tuple значень кількох полів, тому студенти впорядковуються спершу за групою, потім за середнім балом.

@track_operation("сортування за балом")
def sort_by_grade(students: list[Student], reverse: bool = True) -> list[Student]:
    return sorted(students, key=lambda student: student["average_grade"], reverse=reverse)

def sort_items(items: list[Student], *fields: str, reverse: bool = False) -> list[Student]:
    if not fields:
        raise ValueError("Потрібно вказати хоча б одне поле для сортування")
    return sorted(
        items,
        key=lambda item: tuple(item[field] for field in fields),
        reverse=reverse,
    )

6.5. Closure

create_grade_filter повертає внутрішню функцію predicate, яка пам'ятає minimum після завершення зовнішньої функції (значення зберігається в predicate.__closure__, що перевіряє тест). Так само create_group_filter(*groups) замикає frozenset допустимих груп.

def create_grade_filter(minimum: float) -> Predicate:
    def predicate(student: Student) -> bool:
        return student["average_grade"] >= minimum

    return predicate

def create_group_filter(*groups: str) -> Predicate:
    allowed = frozenset(groups)

    def predicate(student: Student) -> bool:
        return student["group"] in allowed

    return predicate

6.6. Decorators

measure_time виводить час виконання функції, не змінюючи її коду (застосовано до calculate_average). track_operation(label) – параметризований декоратор: зовнішня функція приймає параметр, повертає декоратор, а wrapper після кожного виклику записує операцію в deque та Counter. functools.wraps зберігає ім'я та docstring обгорнутої функції.

def measure_time(func: Callable[P, R]) -> Callable[P, R]:
    @wraps(func)
    def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
        start = perf_counter()
        result = func(*args, **kwargs)
        elapsed = perf_counter() - start
        print(f"[час] {func.__name__}: {elapsed:.6f} с")
        return result

    return wrapper

def track_operation(
    label: str,
    *,
    history: deque[str] | None = None,
    counts: Counter[str] | None = None,
) -> Callable[[Callable[P, R]], Callable[P, R]]:
    target_history = operation_history if history is None else history
    target_counts = operation_counts if counts is None else counts

    def decorator(func: Callable[P, R]) -> Callable[P, R]:
        @wraps(func)
        def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
            result = func(*args, **kwargs)
            target_history.append(label)
            target_counts[label] += 1
            return result

        return wrapper

    return decorator

Побудова індексу коштує O(n) (5.2 мс на 100 000 записів) і окупається вже після 3–6 пошуків. Отже, теоретична складність добре узгоджується з практичним часом: для багаторазового пошуку за ключем потрібно використовувати dict або set.

10. Перевірка правильності

Тести (tests/, unittest) перевіряють пошук обома способами, межі фільтрів, closure, групування, сортування, pipeline, валідацію, агрегації, експорт JSON, декоратори і benchmark. Пакет встановлено в чисте venv через pip install -e ., console commands працюють.

Висновки

Створено модуль аналізу успішності студентів (варіант 1), що продовжує ЛР1: пошук, фільтрація, групування, сортування, агрегація і статистика. Структури обрано за властивостями: list – впорядкований набір, tuple – незмінні константи і складені ключі, set – унікальність і швидка перевірка належності, dict – записи та індекс, collections – групування, підрахунок і журнал операцій. Функції вищого порядку, closures і decorators дозволили змінювати поведінку без зміни основного коду. Експеримент підтвердив теорію: час пошуку в list зростає лінійно, у dict – сталий, і на 100 000 записів різниця перевищує 43 000 разів.
